# Menwe Professional Marksheets

The marksheet UI is designed for three school levels: Lower Primary, Upper Primary, and Junior School.

## Reporting rules
- Lower Primary: rank by Total Marks.
- Upper Primary: rank by Total Marks.
- Junior School: rank by Total Points.
- Every reportable learning area displays Score and Level.
- Levels are derived automatically from percentage using EE1, EE2, ME1, ME2, AE1, AE2, BE1, BE2.
- The final columns are Total Marks, Total Points, and Rank.
- The final summary rows are Total Marks and Mean for each reportable learning area.
- Upper Primary component results remain attributable to their individual teachers while reporting is compiled into the configured learning areas.

## Print requirements
- A4 landscape.
- Repeat table headers on every page.
- Avoid clipped columns and split learner rows.
- Keep the school/class/term heading visible on each printed page.
- Use abbreviated learning-area headers in the compact marksheet.
